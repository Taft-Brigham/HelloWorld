# Overview

As a software engineer, I am continually improving my programming and software development skills by building practical applications and learning industry tools such as Git, GitHub, and Visual Studio Code. This project helped me strengthen my understanding of setting up a development environment, writing and running code, and publishing projects to a public repository.

This software is a simple Hello World application written in Python. The program displays a greeting message to the user through the command line interface.

The purpose of creating this software was to practice the complete software development workflow including coding, version control, documentation, video demonstration, and publishing software online using GitHub.
